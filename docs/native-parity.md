# Rust 功能迁移与验证

[English](native-parity.en.md) · [桌面使用说明](desktop.md)

以本地 Web 版的扫描、清理、项目分析和 AI 模块为对照，补齐原先未迁移的能力。两版使用独立运行记录；桌面版提供 Web JSON 历史导入，旧预览只作历史展示，不恢复清理授权。

| 原版能力 | Rust 入口与验证 |
| --- | --- |
| 一次完整扫描与同步 | 用户目录 / 启动磁盘数据卷；同一快照发布目录、项目、工具、关联与模型结果。超过 60,000 个文件、深层和隐藏目录测试通过，无遍历数量或深度截断。 |
| 后台进度与取消 | 顶部常驻步骤、文件数、文件夹数、占用、耗时、当前路径；数据库写锁下状态与取消仍及时响应。旧结果在重扫完成前保留。 |
| 文件夹与逐文件占用 | 物理占用、内容大小、分类、搜索、大小 / 名称 / 时间排序、全量分页；支持选定目录重新计量并更新祖先和项目总量。 |
| 项目归类与用途 | 项目标记、安装信息、会话显式工作目录、最近的真实项目、编码目录中的记忆标题与用途；父子项目分开查看和清理。 |
| 常见 AI 工具与未知 harness | 共享主流工具目录；结合环境变量、XDG、npm / Python / IDE 安装信息、命令位置、原生应用身份和 Electron ASAR 元数据。普通 SDK 依赖不单独当作工具。 |
| 自动候选识别 | 通用结构样本仅保留字段名、特征、表名及必要本地项目引用。可启用模型识别；分批、缓存与证据变化后更新，不确定结果保留标记。模型不能新增路径或清理规则。 |
| 关联补读与诊断 | SQLite 主库及活动 WAL 的一致性私有副本、相对 / file URI 路径、同一工具范围唯一压缩文件恢复。失效、权限、歧义、损坏压缩和未知数据库明确列出。 |
| 可视化清理 | 冻结逐文件身份、勾选、分页、预览有效期、确认、不可重放；缓存 / 日志 / 会话 / 记忆及下载的安装包；会话和记忆另行确认。 |
| 两种处理方式 | 默认移到废纸篓；永久删除需另行明确确认。按已审阅文件处理，变化、占用、凭据、依赖、数据库、模型和备份保留。逐文件记录原路径、目标、状态与原因。 |
| Mole 四种预览 | clean / purge / installer / optimize，后台输出可查看。 |
| Mole 可选范围清理 | 从新预览清单生成分组与文件清单，冻结完整组身份；只允许支持的缓存 / 日志范围。文件变化则保留整组；未选范围保持不动。 |
| 整次 Mole clean | 单独审阅并确认完整范围的永久清理；固定上游命令、一次性预览、原始输出和操作记录。其余 Mole 命令保持原版的只读预览能力。 |
| AI 清理风险建议 | 工具占用、当前逐文件清单或 Mole 清单；每批 20 项，继续下一批并合并；保留 / 审阅 / 可考虑、风险、依据、不确定性、筛选与导出。 |
| AI 权限隔离 | 判读不发送正文；无文件或命令工具，拒绝追加读取请求。每个文件 / 文件夹的「AI 总结」由点选、覆盖预览及确认单独发起，独立子项目不混入父项目。 |
| Ollama | 模型详情、占用、运行状态、选择连接；移除前再核对模型身份和占用，仅通过 Ollama API 移除具体模型。兼容 Chat Completions 的接口也可连接。 |
| 历史、导出与语言 | JSON / CSV：项目、工具、关联、诊断、建议、两类清单、全部操作记录；清理历史分页、Web 历史导入 / 分页 / 导出；简体中文与 English。 |
| 简约界面与固定操作 | 项目 / 可视化 / Mole 清单有可达的预览与确认操作；AI 子页面收于左侧可折叠导航。保留现有视觉风格。 |

## 本轮验证

2026-10-19，本机 Apple Silicon macOS：

- **62 项 Rust 测试通过**：`parity.rs` 19、`safety.rs` 19、`review.rs` 5、`progress.rs` 5、单元测试 5、索引空间与授权回归 6、紧凑索引回归 3。
- **13 项进度界面测试通过**。
- 打包应用冒烟测试通过：真实 Rust 后台进程、写锁下取消、Mole 路径保护、废纸篓记录、重新扫描及语言持久化。
- **15 组打包应用对等流程通过**：本地模拟模型服务、跨批 AI 建议、候选身份缓存、恶意读取请求、选定总结、诊断、导入与导出、本地模型保护与移除、四种 Mole 预览、可选清单和整次清理、取消时的输出与记录、重启授权失效。
- 实际 macOS / WebKit 窗口检查：完整扫描状态、项目分类、文件夹占用、130 项分页预览、目录重新计量、总结覆盖预览及结果、候选元数据、AI 建议、关联诊断、Mole 清单和确认入口、中英文导航。
- `.app` release 构建及 ad-hoc 签名验证通过。测试源码见 [`native/tests/`](../native/tests/)、[`test-native-smoke.py`](../scripts/test-native-smoke.py)、[`test-native-parity.py`](../scripts/test-native-parity.py)，CI 执行相同流程。

清理、永久删除和模型移除只对临时样例及本地模拟服务执行。测试不证明任意 Mac、全部未知 harness 或第三方云盘都能被无误识别；Intel、真实云盘停顿和真实模型下载 / 移除尚未实机验证。完整磁盘扫描仍受 macOS 文件权限、挂载卷和文件系统状态约束；这些状态会显示在结果与诊断中。

扫描进度增加容量快照：每次开始前读取总量与可用空间，首次以已用空间估算，有同范围完整历史时采用历史占用。百分比标记为「预计进度」，为归类、计量与模型检测预留阶段，成功完成才到 100%；取消和失败不补到完成。

索引存储回归覆盖旧格式中断重试、逐条字段一致性、64 位无符号文件身份、硬链接索引、父目录查询计划、跨快照更新/删除隔离，以及压缩副本校验和物理空间回收。样例使用临时目录，不包含真实扫描数据。

- v0.2.1 界面核验：合并项目入口；全部 / AI 记录筛选、切换清空勾选与预览、仅选定项目生成预览、旧 `#ai` 链接跳转及中英文文案通过。

- 本地界面更新核验：本地模型移入设置；检测、使用、移除确认与运行中模型保护保留。工具重复入口合并，旧工具/模型链接兼容；目录展开、中英文及快速切换标题通过。

- 设置排版核验：分组卡片、模型状态与操作、空列表、连接/索引入口，中英文和 960px 窄窗口无横向溢出；慢速模拟检测时进度及停止按钮可见，结束后收起；实际 WebKit 设置页与打包冒烟通过。
