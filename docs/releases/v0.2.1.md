# v0.2.1 · 开发预览 / Development preview

## 更新

- 统一项目清理入口，支持「全部项目 / 含 AI 记录」筛选。原 AI 按项目链接自动跳转，切换筛选会清空勾选和预览。
- 米白、暖浅灰与象牙白背景，减淡本地纸纹，保留橙色操作与选中状态。
- 紧凑扫描索引，复用扫描与父目录标识；完整保留文件路径、身份、大小和分类。旧索引自动迁移，保留最新完整扫描、设置及清理历史。
- 回收索引空闲页，提供索引占用、优化和单独确认的重建入口；磁盘空间不足时显示可操作的错误。
- 集中文件访问权限入口、稳定应用启动位置与重复实例保护。完整磁盘访问仍需在 macOS 系统设置中手动授权。

本机已有 4,522,874 条索引记录的迁移实测：索引由 11.80 GB 降至 3.88 GB，减少约 67%，记录数量及完整扫描统计保持一致。这是单机实测，压缩幅度与迁移耗时取决于数据。

## 下载与升级

下载 `Minorminor-v0.2.1-macos-arm64.zip`，退出旧版后解压，将 `Minorminor.app` 替换到原安装位置。运行不需要 Node.js 或 Rust。首次升级会整理旧索引，期间可查看后台进度；无需删除原扫描记录。

提供 **macOS Apple Silicon（arm64）** 构建，目标 macOS 12+。应用仅 **ad-hoc 签名，尚无 Apple Developer ID 签名或公证**；首次打开可能被 macOS 阻止，确认来源后按系统「隐私与安全性」提示处理。未验证 Intel 和全部旧版 macOS。移动或重签名应用可能需要重新授权。

`Minorminor-v0.2.1-source.tar.gz` 包含项目源码及固定版本 Mole。GitHub 自动生成的源码压缩包不包含子模块内容。`BUILD-INFO.json` 记录构建来源，`SHA256SUMS.txt` 提供校验值。
