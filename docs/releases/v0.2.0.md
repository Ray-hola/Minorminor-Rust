# v0.2.0 · 开发预览 / Development preview

首个 Rust 桌面预览版，提供 **macOS Apple Silicon（arm64）** 应用。构建目标为 macOS 12+；已在 macOS 15 CI 与本机 Apple Silicon 上验证，未实测 Intel 或全部旧版 macOS。

## 更新

- 一次后台扫描同步目录占用、项目、AI 工具及关联结果；保留进度、取消与重启后的扫描状态。
- 文件夹和逐文件占用、用途与分类；勾选范围后预览、确认，默认移到废纸篓。
- Mole 四种预览、可选范围清单与单独确认的整次清理。
- AI 元数据建议及未知工具候选识别；文档读取权限禁用，选定资源的「AI 总结」另行确认。
- 暖纸色与陶土橙界面、统一应用图标、简体中文与 English。

## 下载与运行

下载 `Minorminor-v0.2.0-macos-arm64.zip`，解压后将 `Minorminor.app` 拖入「应用程序」。运行不需要 Node.js 或 Rust。

应用为 **ad-hoc 签名，未经过 Apple Developer ID 签名或公证**。macOS 可能阻止首次打开；确认下载来源可信后，按系统「隐私与安全性」中的提示处理。扫描受权限保护的目录需自行授予相应文件访问权限。

百万级文件的项目归类与首次明细加载仍可能等待数分钟；进度为估算值。权限失败和云端超时会保留诊断，不能视作已读取全部受限文件。预览版建议先审阅缓存与日志，再确认处理范围。

`Minorminor-v0.2.0-source.tar.gz` 包含项目源码和固定版本 Mole；GitHub 自动生成的 Source code 压缩包不包含子模块内容。`BUILD-INFO.json` 记录构建来源，`SHA256SUMS.txt` 提供 SHA-256 校验值。

## English

The first Rust desktop preview provides an **Apple Silicon (arm64)** app targeting macOS 12+. Verified on macOS 15 CI and a local Apple Silicon Mac; Intel and every older macOS version have not been tested.

Background scans synchronize storage, projects, AI tools and associations. Browse folder/file sizes, select and review cleanup, use Mole previews and scoped lists, request metadata-only AI advice or explicitly summarize selected resources. Includes the warm theme, updated app icon and Chinese/English interface.

Unzip the arm64 download and drag `Minorminor.app` into Applications. No Node.js or Rust runtime is required. **Ad-hoc signed, without Developer ID signing or notarization**; macOS may block first launch. Follow native Privacy & Security prompts only after verifying the source. Protected paths need the appropriate file access permission.

Million-file project assignment and first detail loads may take minutes. Progress is estimated; denied or timed-out reads remain diagnostic gaps. The full source archive includes pinned Mole; GitHub's automatic source archives omit submodule contents. Build provenance and SHA-256 checksums are attached separately.
