# v0.2.2 · 开发预览 / Development preview

## 更新

- 重新设计设置页：模型连接、本地模型、存储与权限、数据与记录分组，统一信息与按钮对齐，窄窗口自动上下排列。
- 本地模型移入设置，保留检测、使用、运行状态、占用、参数和移除前确认；正在使用的模型仍禁止移除。
- 合并重复的「工具概览」「目录与缓存」入口为「工具与目录」，保留候选识别、目录展开、分类、识别依据和清理预览。
- 旧模型与目录链接自动跳转；修复快速切换页面时可能残留旧标题的问题。
- 设置页只在后台任务运行时显示进度与停止按钮，已结束的扫描状态保留在总览中。
- 更新简体中文、English 文案及使用说明，沿用 v0.2.1 的紧凑索引与逐文件预览确认流程，不更改索引格式。

## 下载与升级

提供 **macOS Apple Silicon（arm64）** 应用，目标 macOS 12+。退出旧版，解压 `Minorminor-v0.2.2-macos-arm64.zip`，将 `Minorminor.app` 替换到原安装位置。无需 Node.js 或 Rust，已有扫描结果、设置和清理历史沿用。

**本版仍为 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。** 首次下载可能被 macOS 拦截；确认来源后按系统「隐私与安全性」提示处理。完整磁盘访问仍需在 macOS 中授权，重新构建或移动应用可能需要重新授权。本次不提交 Apple 公证，也不包含之前在本地准备的公证工作流。

`Minorminor-v0.2.2-source.tar.gz` 包含源码和固定版本 Mole；GitHub 自动生成的源码包不含子模块内容。`BUILD-INFO.json` 记录版本、来源与构建信息，`SHA256SUMS.txt` 提供附件校验值。许可沿用 GPL-3.0-only。

## English

- Redesigned Settings with grouped model connection, local models, storage/access and data/history controls. Information and actions align consistently; narrow windows stack the groups.
- Local models now live in Settings, retaining detection, selection, status, size, parameters and removal confirmation. Running models remain protected.
- Merged duplicate Tools / Directories and caches entries into Tools and directories, retaining candidate identification, browsing, categories, evidence and cleanup previews.
- Legacy links redirect automatically. Fixed stale titles when switching pages quickly.
- Settings shows progress and Stop while a task is running; completed scan status remains in Overview.
- Updated Chinese/English labels and guides. Compact indexing and per-file confirmation from v0.2.1 remain unchanged; no index format change.

Quit the old app, unzip the **Apple Silicon (arm64)** download and replace the app at its original location. Targets macOS 12+; no Node.js or Rust runtime required. Existing scans, settings and cleanup history are retained.

**Ad-hoc signed, without Developer ID signing or Apple notarization.** macOS may block first launch; follow native Privacy & Security prompts after verifying the source. File access still requires system authorization, which may need renewal after a rebuild or move. No notarization is submitted; the locally prepared notarization workflow is excluded from this release.

The full source archive includes pinned Mole; GitHub-generated source archives omit submodules. Build provenance and SHA-256 checksums are attached. GPL-3.0-only; Mole remains pinned at `6650d0958282aa8052cd2bfeee15f67b17fe613b`.
