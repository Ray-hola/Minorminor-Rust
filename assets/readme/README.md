# 展示素材

`project-cleanup.jpg` 和 `project-cleanup.en.jpg` 来自实际运行的 Rust 桌面界面，分别展示简体中文与 English。截图使用隔离临时目录中的 Atlas、Paper、Notes 示例项目，不包含真实用户文件或模型内容。

更新截图：先构建桌面应用，然后在仓库根目录运行 `python3 assets/readme/demo.py`。打开输出的本地地址，进入项目清理，分别切换语言并截图。按 Ctrl+C 停止，临时示例目录会删除。

静态徽章的事实来源：版本、Rust 要求与 GPL 标识来自 `native/Cargo.toml` 和根目录 `LICENSE`；macOS 要求来自 `native/Info.plist`；Mole 来源与许可见 `UPSTREAM.json` 及子模块许可证。Actions 徽章使用实际工作流状态。修改这些事实时同步两个 README 与对应徽章。
